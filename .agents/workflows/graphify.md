# Workflow: graphify

1. Check if `graphify` is installed. If not, install via `pip install graphifyy`.
2. Follow the graphify skill to run the graph extraction or update pipeline.
3. If no path argument is given, use `.` (current directory).
4. Run `graphify update .` after code modifications to maintain AST freshness without API costs.
